# مهارتینو | Maharatino

پروتوتایپ تعاملی پلتفرم یادگیری مهارت‌های دیجیتال، کامپیوتر و هوش مصنوعی برای نوجوانان.

این مخزن شامل کدهای خروجی Figma Make و تنظیمات انتشار خودکار روی GitHub Pages است.

> نسخه فعلی یک پروتوتایپ فرانت‌اند است؛ احراز هویت، پرداخت آنلاین، ذخیره‌سازی و اتصال واقعی هوش مصنوعی به بک‌اند نیاز دارند.
